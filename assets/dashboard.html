Welcome to SiliconNet
Before SiliconNet changes macOS proxy settings, review what will happen and start it yourself.

SiliconNet runs locally on your computer. It listens on 127.0.0.1, stores data in your user Library folder, and only enables proxy integration after you confirm this setup.

Local onlyDashboard and proxy bind to 127.0.0.1. No cloud account or remote control is used.
Proxy with consentmacOS proxy integration stays off until you press Start SiliconNet. You can reset it from the menu bar or dashboard.
Visible data folderConfig, logs, stats and AI cache are kept in this folder so you can inspect or delete them.
